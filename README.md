## Key Metrics to Compare

When choosing a prop firm, compare these critical factors:

| Metric | What to Look For |
|--------|-----------------|
| **Profit Target** | Lower is easier (6-10% typical for step 1) |
| **Max Drawdown** | Static is more forgiving than trailing |
| **Daily Loss Limit** | 3-5% is standard |
| **Profit Split** | 80-90% is competitive, 100% exists |
| **Payout Frequency** | Weekly or bi-weekly is best |
| **Min Trading Days** | 0-5 days is ideal |
| **Platforms** | MT4/MT5 for forex, Rithmic/Tradovate for futures |
| **Fee Refundable** | Some firms refund the challenge fee on first payout |
