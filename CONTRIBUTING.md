# Contributing to Awesome Prop Trading

Thanks for your interest in contributing!

## Guidelines

### Adding a Resource

- Make sure the resource is **verified and active**
- Prop firms must be **operational with real payouts**
- Tools must be **functional and maintained**
- No referral/affiliate links (use direct URLs only)
- Educational content must be **free or clearly marked as paid**

### Format

```markdown
- [Resource Name](https://url.com) - Brief description of what it offers.
```

### Pull Request Process

1. Fork the repository
2. Add your resource in the appropriate section
3. Keep alphabetical order within sections
4. Submit a PR with a clear description of what you added and why

### Quality Standards

- No spam, scams, or unverified firms
- No firms with documented payout issues
- No tools that require payment without a free tier
- Educational content must provide genuine value

## Questions?

Open an issue and we'll help out.
